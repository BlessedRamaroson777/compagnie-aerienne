Information
Rôle du billet dans le système :
  • Identité : Le billet relie un passager (via une réservation) à un vol spécifique
  • Attributs clés : ID unique, réservation, siège, prix, statut (EMIS, ANNULE, UTILISE, REMBOURSE)
  • Relations :
    • Billet → Réservation → Client (qui voyage)
    • Billet → SiègeVol → Vol programmé (où et quand)
    • Billet → Paiement (transaction financière)
  • Fonctionnalités :
    • Vérifier si un passager peut embarquer
    • Calculer le nombre de sièges occupés sur un vol
    • Statistiques et rapports financiers (revenus par vol, par classe)
    • Gérer les modifications et annulations via le statut
Résumé : Le billet est l'objet central qui matérialise la réservation d'un siège pour un passager sur un vol précis. Sans billet, le passager n'a pas de droit de voyage.
